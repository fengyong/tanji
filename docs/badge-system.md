## 一、调研摘要:抖音官方探店达人等级体系

**体系名称**:抖音生活服务「达人带货力等级」(探店达人侧,抖音来客/巨量本地推/探店宝同源)。

**关键结论**:

1. **共 9 级(Lv1~Lv9),另设 Lv0**:Lv0 分配给新达人和违规达人(信用分低于 60 分)。2024 年 8 月新版从 8 级扩为 9 级,并拆分为「视频带货力」与「直播带货力」两条线。
2. **9 级 3 阶段,考核指标分层**:
   - Lv1–Lv3(本地活跃探店达人):考核「本地商户探店数」(投稿量)+「本地商户核销数」(履约);
   - Lv4–Lv6(稳定出单的职业达人):考核「有效支付金额」「有效核销金额」「Top10 视频稿均播放量」;
   - Lv7–Lv8(有粉丝号召力的宝藏达人):在五项指标之上再加「稿均粉丝支付金额」「稿均粉丝播放量」。
3. **按自然月动态升降**:每月 6 日按上月数据评定当月等级,展示至次月 5 日——即官方体系是"可升可降"的周期评级,不是生涯里程碑。
4. **等级即权益**:等级越高,探店车马费越高(广州市场参考:Lv3 约 30–50 元/条 → Lv5 约 500 元起 → Lv6 约 2000–3000 元/条),佣金比例越高(一般上限约 8%);商家在探店宝发单时按达人包等级(如 L3)筛选,等级直接是接单门槛。
5. **履约是硬指标**:官方另设达人信用分规则,低质履约(到店不可核销、关键信息缺失)直接扣分降级。

**对探记的启示**:抖音用"投稿量→交易额→粉丝质量"三层递进;探记达人已处于"交易端"(商家预约制),不存在曝光/核销数据,所以应借鉴其**分层思想**(先单量、后金额、再口碑)而非照搬指标。官方 9 级对个人工具过细,探记收敛为 **5 级**(对齐行业"L 级"心智)。

## 二、设计原则

1. **5 级封顶、10 勋章封顶**,每个条件一句话能讲清,不看说明书就能懂。
2. **只升不降**:探记是个人生涯工具,等级/勋章是里程碑,不做官方那种月度降级(降级只产生挫败感);月度波动交给 30 天滚动勋章表达。
3. **阈值必须够得着**:所有门槛用大王数据推演——够不着的勋章是"死勋章",比没有更伤(原草稿「爆单≥6单」「王牌日≥¥3000」在大王当前量级下永远不会亮,已下调)。
4. **正面激励优先**:奖励"做到了什么"(收得快、客户回头),不奖励"没犯错"(零逾期类进备选池)。

## 三、达人等级(5 级)

### 3.1 等级表

| 级 | 名称 | 晋入门槛(双轨,任一达标即升) | 大王耗时推演 | 晋级激励文案 |
|---|---|---|---|---|
| 1 | 🌱 跑店新人 | 累计完成 **10 单** 或 累计实收 **¥3,000** | ~1 周(首周约 11 单) | 「第一单开张,镜头已经架好——探店之路,正式开机!」 |
| 2 | 📣 接单熟手 | 累计完成 **30 单** 或 累计实收 **¥10,000** | ~26 天(首月内) | 「30 单到手,商家开始记住你的名字了。」 |
| 3 | 🎬 出片能手 | 累计完成 **80 单** 或 累计实收 **¥30,000** | ~2 个月 | 「出片又快又稳,你已经是可以被信赖的专业选手。」 |
| 4 | 🔥 满档达人 | 累计完成 **160 单** 或 累计实收 **¥60,000** | ~3 个半月 | 「档期排到下个月——你现在是最抢手的人。」 |
| 5 | 👑 城市王牌 | 累计完成 **300 单** 或 累计实收 **¥100,000** | ~6 个半月 | 「一座城的店,都认得你的镜头。」 |

### 3.2 双轨制推荐:单数 OR 实收(取"或",不取"与")

- **推荐双轨**:「累计单数」奖励走量型(渠道单多、单价低但勤快),「累计实收」奖励高客单型(直客少而精)。任一达标即晋级——两种打法都被承认。
- **不取"与"**:AND 逻辑会让单量大、收款周期长的达人卡在半路(周结渠道实收天然滞后 1~2 周),且解释成本高。
- **进度展示**:两条进度条都显示,高亮"更接近达标的那条"作为主进度。
- 单数口径 = 实际拍摄日期非空的完成单;实收口径 = 收款流水金额合计(与"档期总额"区分,实收才是真到手)。

### 3.3 大王今天打开 App 的推演(首次导入 11 月数据,从零档案)

- **等级:直达 Lv2 接单熟手**(46 单 > 30 ✓;¥11,630 > ¥10,000 ✓,双轨全过)。
- **距 Lv3 出片能手**:单数轨还差 **34 单(约 3 周)**,实收轨还差 **¥18,370(约 1 个半月)** → 主进度显示"还差 34 单 · 约 3 周",实收轨为副进度。
- 首次导入做**静默回填 + 一张汇总弹窗**("恭喜直达 Lv2,点亮 8 枚勋章"),不逐个弹窗轰炸。

### 4.1 对旧"单日勋章"草稿的校准

| 草稿 | 问题(按大王数据) | 新方案 |
|---|---|---|
| ⭐忙碌日 ≥3 单 | 可达,保留 | 不变 |
| 🔥爆单日 ≥6 单 | 大王单日峰值 5 单,**永远不亮** | 下调为 **≥5 单**(她的真实巅峰,罕见但够得着) |
| 💰千元日 ≥¥1,000 | 可达(2~3 单日即破千),保留 | 不变 |
| 💎王牌日 ≥¥3,000 | 大王峰值 ¥2,630,**永远不亮** | 下调为 **≥¥2,500**(11 月已惊险达成,保持稀有感) |

### 4.2 维度覆盖核对

单日·单数(2、3)/ 单日·收入实收(4、5)/ 30 天滚动(6)/ 累计·单数(1、7)/ 累计·实收(8)/ 复购口碑(9)/ 收款速度(10)——用户点名的六个维度全覆盖,且以一次性成就为主(6/10)。

### 4.3 备选池(本期不做)

- 🛡️ 全月零逾期:奖励"没犯错",激励性弱,且需定义逾期口径;若后续做 streak 玩法再加。
- 📅 月度百单:大王量级的 2 倍以上,死勋章,不做。
- 🤝 五店老友(复购 5 个商家):留给二期,避免首版条件过密。

## 五、展示位置建议

1. **首页**:
   - 头部用户名旁挂**等级小徽章**(如「📣 接单熟手」彩色小标),点击跳转成就页;
   - 新达成勋章:**toast + 首页顶部横幅**当天可见,次日自动收起;同日多枚合并为一条("今日解锁 3 枚勋章 →")。
2. **统计页(成就卡,主阵地)**:
   - 顶部「当前等级 + 距下一级双进度条」(主进度=更近的那条,副进度弱化显示,文案如"还差 34 单 · 约 3 周");
   - 下方**勋章墙**:3×3 或 5×2 网格,已点亮彩色 + 达成日期,未点亮灰色剪影 + 条件文字(剪影本身就是"想收集"的钩子);可重复勋章在角标显示 ×N。
3. **行程月历(单元格小,克制)**:
   - 格子里**不放勋章主体**,只在"达成日"当天右上角放一个 8~10px 的 **emoji 角标**(如爆单日当天 🔥),与现有档期圆点错位排布;
   - 长按/点按某天,在日详情里列出当天触发的事件("🔥 爆单日 · 5 单 / 💰 千元日");
   - 月历底部保留一行图例,保证角标可读。
4. **设置/我的页**:成就总览入口 + "隐藏成就弹窗"开关(给不想被打扰的用户)。

## 六、实现要点(纯前端)

1. **全部可从现有数据推导,零后端**:
   - 累计完成单数 = 「实际拍摄」日期非空的订单数;
   - 累计实收 = 收款流水金额合计;
   - 单日聚合 = 按"实际拍摄日期"分桶计数/按"收款日期"分桶求和;
   - 30 天滚动 = 以任一天为终点的 30 日窗口单数,取历史最大(用于勋章判定);
   - 复购 = 商家名(归一化后)在历史订单中出现 ≥2 次;
   - 回款速度 = 收款流水时间 − 实际拍摄日期 ≤7 天。
2. **进度持久化到 settings 表**(无法从数据反推的部分必须存):
   ```json
   { "level": 2, "levelAt": 1763500000000,
     "badges": { "busyDay": { "count": 6, "firstAt": ... },
                 "firstOrder": { "firstAt": ... } } }
   ```
   存"已达成快照"而非每次现算的原因:① 勋章达成时间应锁定为**首次业务日期**,数据后续增删改不会让历史勋章消失;② 阈值未来调整时已达成的不回退;③ 弹窗只弹"settings 里没有的新达成",天然去重。
3. **重算时机**:每次订单/流水增删改后重算 → 与 settings 比对 diff → 新达成入队弹窗。
4. **等级只升不降**;勋章计数只增不减(与官方月度降级体系刻意不同)。
5. **首次导入历史数据**:静默回填所有达成项,只弹一张汇总卡。
6. 弹窗节流:同一天合并;同一次编辑触发的多枚勋章合并为一张列表卡。
