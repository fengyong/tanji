常见问题

我的数据存在哪？会被上传吗？

全部存在你自己的设备上（应用沙盒内的数据库 + 本地镜像双副本）。应用没有服务器，不会上传；卸载应用数据就没了。隐私政策有完整说明。

怎么备份？多久备一次？

「统计 → 数据管理」里导出 JSON 或 .db，存到文件 App / iCloud。建议每周一次。添加到主屏幕不能替代备份，系统随时可能清理浏览器数据。

换手机了，数据怎么带走？

旧设备导出 JSON → 新设备安装后进入「统计 → 切换到工作数据」→「导入 JSON 备份」，核对预览后确认替换。导入会校验订单 ID、金额、时间与流水，不一致会直接拒绝，不会静默改账。

打开后是演示数据，怎么换成我自己的？

「统计 → 切换到工作数据」。工作数据与演示数据是两套独立保存的，切换、导入、清空都只影响当前这一套，不会互相覆盖。

怎么确认没记错账？

已经收过款的订单会锁定总价和定金，必须先撤销相应流水才能改价；定金不会超过总价；零元单直接结清；重复收款不会重复入账。

「隐藏金额」是加密吗？

不是。隐藏金额只是界面上不显示，导出文件是完整明文。共享给他人前请自行判断。

每日催收提醒怎么设置？为什么没弹？

「统计 → 逾期催收每日提醒」打开后，每天 09:00 本地通知，只报逾期条数和最长天数、不含金额。收完款或删除订单后，旧的排程提醒会被同步取消。没弹的话检查一下系统「设置 → 通知 → 探记」是否允许通知。

提示「保存失败」怎么办？

先别关页面。立即导出 JSON 备份，再重试保存。如果持续失败，设备存储可能不足——清理空间后重开应用。读取异常时应用会暂停写入以防覆盖新数据，此时仍可尝试导出替换前备份。

离线能用吗？

能。应用支持离线运行，断网后照常记录和统计；联网后也不会自动同步（因为本来就没有服务器）。

导出的 .db 能用别的软件打开吗？

可以，用任意 SQLite 工具打开。表结构与 Web 版一致，但原生 App 内部库多一列 mode（区分工作/演示数据），跨端搬运请用 JSON 备份。

系统要求

iPhone 版iOS 15.0 及以上
Web 版支持 Web Locks 的现代浏览器（Safari 16.4+ / Chrome 96+ 等），需 HTTPS 或 localhost
离线支持；首次加载后本地缓存
网络不需要。应用不发起任何网络请求

同一地址只允许一个标签页写入，其他标签页会变为只读。手机上请用「添加到主屏幕」打开，不要在多个标签页同时操作。
